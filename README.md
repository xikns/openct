1. 系统概述
本系统专为中小学班级管理设计，提供积分管理、班级风采展示、积分抽奖、惩罚抽奖等功能。

教师：管理学生、加减积分、编辑首页、设置抽奖、查看日志。

学生：查看积分排行、修改密码头像、参与抽奖（消耗积分）。

学生管理员：仅可管理积分加减（由教师指定）。

2. 环境要求
PHP 7.4 或更高版本

MySQL 5.7 或更高版本（需支持 utf8mb4）

Apache / Nginx 服务器

浏览器：Chrome、Edge、Safari 等现代浏览器

3. 安装指南
将项目所有文件解压到网站根目录（如 public_html）。

确保 uploads 目录有写入权限（Linux 通常为 755，必要时设为 777）。

在浏览器中访问你的网站地址（例如 http://你的域名/）。

首次访问将自动跳转到 安装向导（install.php）。

安装向导分两步：

第一步：填写数据库主机（一般 localhost）、数据库名、用户名、密码，点击“测试连接”。

第二步：设置管理员账号（教师角色），填写用户名、姓名、密码（≥6位），点击“完成安装”。

安装成功后，系统会自动跳转到前台首页。建议删除 install.php 文件以提高安全性。

若需重新安装，只需删除 includes/config.php 文件，再次访问首页即可进入安装向导。

4. 前台使用
4.1 首页
展示班级名称、积分累计时间、截止倒计时。

积分榜前三名：圆形头像、姓名、积分。

班级风采轮播图：教师可在后台上传照片。

页面顶部导航栏：若已登录，显示“后台”按钮（教师/学生管理员可见）和“退出”；未登录则显示“登录”。

4.2 登录与注册
点击首页“登录系统”进入登录页。

学生登录：使用学号和密码。

教师登录：使用安装时创建的管理员账号。

若管理员开启了注册开关，登录页会显示“注册新账号”链接，学生可自行注册（填写学号、姓名、密码）。

忘记密码：需填写注册时绑定的邮箱，通过验证后可直接重置密码。

4.3 学生个人中心（登录后）
查看当前积分、修改密码、上传头像（支持 jpg/png/gif）。

查看个人积分变动记录（谁操作的、时间、原因）。

4.4 积分抽奖（消耗积分）
教师开启抽奖后，学生登录首页可见“🎁 积分抽奖”入口。

进入抽奖页，可看到转盘动画，每次抽奖消耗指定积分（如10分）。

积分不足时按钮禁用；抽奖后实时扣除积分，可连续抽奖直到积分不够。

教师可以代表学生抽奖：在抽奖页选择学生下拉框，切换学生后为其抽奖，积分由该学生承担。

4.5 惩罚抽奖（仅教师）
教师登录后，在抽奖页切换到“惩罚抽奖”标签。

系统会自动列出积分最低的几名学生（人数由教师设定）。

选择学生后点击“惩罚”，转盘显示惩罚奖品，不消耗积分。

5. 后台管理（教师）
登录后点击顶部“后台”进入。侧边栏菜单包括：

5.1 仪表盘
显示积分前十名（带进度条）和倒数五名，用于快速了解班级情况。

5.2 积分管理
学生列表：显示头像、姓名、学号、当前积分。

操作：点击“加分”或“减分”，输入分值和原因，自动记录日志。

批量导入CSV：上传 CSV 文件（格式：学号/姓名, 变动分值），可批量调整积分。

5.3 用户管理
搜索用户、分页展示所有用户。

添加学生：手动填写学号、姓名、密码（默认123456）、邮箱。

批量导入学生：上传 CSV 文件（格式：学号,姓名,密码），自动跳过重复学号。

修改角色：下拉框可将学生设为积分管理员（该角色登录后只能看到积分管理菜单）。

删除用户：仅可删除学生或学生管理员，不能删除教师或自己。

5.4 首页编辑
修改班级名称、积分开始/结束时间。

上传/删除班级风采轮播图，可排序（数字越小越靠前）。

点击“预览首页效果”打开新窗口查看前台变化。

5.5 系统设置
网站标题（显示在浏览器标签页）。

开放注册开关：开启后学生可在登录页自行注册。

5.6 操作日志
所有积分变动记录（包括抽奖扣除的积分），显示学生、变化值、原因、操作人、时间。

支持按学生姓名或操作人搜索，不可编辑。

5.7 抽奖设置
积分抽奖：

开关：控制前台是否显示抽奖入口。

每次消耗积分：学生每抽一次扣除的积分值。

管理积分奖品：添加、删除奖品，设置名称、权重（概率）和总数量。

惩罚抽奖：

开关：控制教师是否可使用惩罚抽奖。

最后几名人数：决定自动加载的惩罚学生数量。

管理惩罚奖品：添加、删除惩罚奖品（不消耗积分）。

6. 抽奖模块详解
6.1 奖品权重说明
抽奖概率 = 该奖品权重 / 所有奖品权重之和。
例如：奖品A权重10，奖品B权重20，总权重30，则抽中A的概率为 1/3，B的概率为 2/3。

6.2 积分抽奖流程
教师在后台上传积分奖品，设置开关和消耗积分。

学生进入抽奖页，确认积分足够后点击转盘中间按钮。

系统随机抽取奖品，扣除积分，记录日志。

积分实时更新，可连续抽奖。

6.3 惩罚抽奖流程（仅教师）
教师设置惩罚开关、惩罚人数、惩罚奖品。

在抽奖页切换到“惩罚抽奖”标签，系统默认显示积分最低的N名学生。

教师选择学生，点击“惩罚”，转盘抽取惩罚奖品，不扣积分，记录惩罚日志。

7. 常见问题
Q：安装时提示“数据库连接失败”
A：检查数据库主机、用户名、密码是否正确；若为虚拟主机，数据库主机可能不是 localhost，请咨询主机商。

Q：批量导入学生报错
A：请确保上传的是 CSV 或 TXT 文件，且格式为 学号,姓名,密码。Excel 用户请先“另存为 → CSV UTF-8”。

Q：学生忘记了密码怎么办？
A：点击登录页“忘记密码”，输入学号和注册邮箱验证后重置密码。若邮箱未填写，请联系教师在后台删除该学生后重新添加。

Q：抽奖时提示“网络错误”
A：通常是 session 过期或服务器配置问题。请刷新页面重新登录，或检查服务器 PHP 错误日志。

Q：如何彻底重新安装？
A：删除 includes/config.php 文件，再访问网站首页即可进入安装向导。注意：此操作会清空所有数据！

Q：能否修改默认头像？
A：替换 assets/default-avatar.png 为你自己的图片即可（保持文件名和尺寸）。

提示：本系统代码完全开源，可自由二次开发。如需自定义样式，请修改 assets/css/style.css；功能扩展请参考现有模块结构。
