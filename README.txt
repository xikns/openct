📦 班级积分管理系统 安装说明

环境要求：PHP 7.4+，MySQL 5.7+，支持 Apache/Nginx

安装步骤：
1. 将压缩包解压到网站根目录（或任意子目录）
2. 确保 web 服务器对 uploads/ 目录有写入权限
3. 在浏览器中访问该目录的地址，系统会自动跳转到安装向导（install.php）
4. 按照向导填写数据库信息、设置管理员账号
5. 安装完成后立即删除 install.php 文件（可选，但建议删除）
6. 默认管理员账号为你安装时设置的账号，教师角色，拥有全部后台权限

注意事项：
- 数据库字符集需为 utf8mb4
- 如需重新安装，只需删除 includes/config.php 并再次访问首页即可
